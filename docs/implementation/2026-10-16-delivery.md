## Deliberate MVP limits

- Local configured-price reservations are not a provider invoice hard cap. Unknown/zero-placeholder prices fail closed; external tool charges and provider noncompliance cannot be bounded by these client checks. Budget enforcement is scoped to the new template path, not every ordinary chat. Interrupted budgeted templates require reviewing prior spend/effects and a new budget; generic checkpoint replay cannot drop the original contract.
- The action ledger does not promise external exactly-once execution or automatic reconciliation. Remote cancellation is best-effort. Local source/model configuration snapshots cannot freeze provider aliases or remote MCP internals.
- Team acceptance checks validate declared structure; they do not prove semantic quality. Declared write ownership is not an OS file lock.
- Scheduler claims are single-process. Existing future-schedule backoff is retained; arbitrary failed external writes are not automatically replayed. Custom business dedupe policies and distributed leases are not added.
- Snapshots are explicit local copies, capped at 5 MiB/file, 10 versions/artifact and 50 snapshots/50 MiB per session. Limits refuse additional saves rather than delete history. Binary/large text compares hash/size; no semantic office-document diff or backup guarantee.
- Memory correction applies to the fact store; compiled summaries remain separate. Model benchmark tasks are bounded response/decision cases, not full live-tool journeys.
- Project knowledge spaces and self-hosted remote workers remain deferred as agreed.

## Independent review corrections and platform boundary

Cross-review identified missing coverage beyond the earlier passing mocks: the installed SDK's active transport is `streamFunction` rather than the constructor option `streamFn`; real SDK agent-loop regressions now cover bounded dispatch, unknown usage and cancellation. Related existing provider/stream/cache wrappers select the active SDK slot while preserving the older slot fallback. Approval checks now re-read permission mode and authorization scope after waiting. Explicit ordinary workflow budgets cannot be silently reset by recovery.

Content snapshots require an OS-backed check of the opened file handle's canonical path, including parent-directory replacement races. Linux supports this check through `/proc/self/fd`. Windows/macOS currently fail closed for snapshot capture, historical content preview/export and content comparison; the UI reports this capability limitation before interaction. Original registered-file preview/export and historical snapshot metadata remain available. This is a significant Windows feature limitation, not completed cross-platform snapshot acceptance. Native trusted-handle support is still needed for equivalent Windows/macOS content snapshots.
