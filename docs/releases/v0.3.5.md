# Codia v0.3.5

本版本基于 v0.3.4，合入最新本地源码，重点完善长任务执行、暂停恢复、工具可靠性和 Agent 小队体验，并修复终端启动失败。以下为本次实际代码变更。

## 1. 长任务 Loop 与执行过程

- 为每次任务建立稳定的 `runId`，默认每段额度为 **128 次模型调用、512 次工具调用、60 分钟实际运行时间**。
- 主助手、子助手、Codemode 子调用和关联续轮共享额度；排队、暂停和等待用户批准不占实际运行时间。
- 达到额度后暂停，执行过程内显示原因及“继续／停止”；明确继续后追加一段额度，保留累计用量和原任务标识。
- 增加执行前登记、并行额度控制、状态版本校验和重复继续防护。暂停期间后台图片与子助手结果仍可登记，但不会自行唤起新的模型请求。
- 持久化运行状态、累计额度和待核对动作；重启恢复时不自动重放未知写入。旧操作尚未结束时保持工作区隔离。
- 排队使用从提交时起计算的 15 分钟截止时间，支持取消，重复遇到忙碌状态不重置等待时限。
- 执行过程贯通运行 ID、父工具调用 ID、进度及耗时；同一任务的续轮归入原过程区域，支持实时事件和历史恢复。

## 2. Workflow 恢复

- 增加版本化累计预算账本，保存步骤、模型调用、token、费用、运行耗时和未结算预留。
- 恢复时沿用剩余额度，并校验任务定义及模型配置；完成动作复用已有结果。
- 旧账本证据不足、预算耗尽、未知写入、损坏记录或旧进程仍活跃时继续阻止自动续跑，避免重复执行和预算重置。

## 3. 本地文件与工具调用

- 编辑绑定读取时的内容版本，同一路径助手写入串行执行；检测外部修改后明确返回冲突。
- 普通文件改为同目录临时写入、落盘和替换，失败时保留原文件。
- 启用检查点时，备份失败会阻止对应写入并给出错误；明确任意 Shell 修改的恢复覆盖范围。
- 受管搜索工具固定 ripgrep 15.2.0、fd 10.5.0 和校验值，下载支持取消；已有可用系统工具继续优先使用。
- 大结果保留最多 2 MiB 的结果文件／资源引用，并说明截断情况。
- Windows 沙箱不支持的禁网组合继续明确拒绝，移除建议默认关闭沙箱的引导。

## 4. Harness 与记忆召回评估

- 修复报告模块移动后的相对导入错误，恢复原文本／决策评测入口。
- 新增 `eval:agent-runtime`，通过确定性模拟模型实际执行生产工具链，覆盖文件修改、检查失败后修复、并行工具、Codemode、测试插件、MCP、取消、额度暂停、恢复及错误成果负对照。
- 模拟评测使用独立工作区和测试配置，不自动调用收费模型或发送真实社交消息；缺少环境组件会标记阻塞，不算通过。
- 召回报告分别统计候选召回、最终注入召回、Precision@K 和失败率；有标准答案的失败样例纳入分母。
- 增加困难 tune／holdout 样例，并改善查询规范化、实体别名及精确匹配排序。合成样例结果不代表真实用户召回率。

## 5. Agent 小队与界面精简

- 小队功能范围内的导航、标题、开关、空态、警告、工作流关联提示和用户可见错误统一使用“Agent 小队”，同步五种语言。
- 关闭状态显示启用说明；提交开关时防重复点击，失败显示错误并恢复服务端确认状态。内部 `channels` 配置、接口和历史 ID 保持兼容。
- 警告说明多助手模型用量、权限限制、停止行为及已发出外部操作可能无法撤回。
- 移除“任务与成果”整页、左侧入口及专属后端路由与展示组件；保留原有自动化记录、工作流、检查点、审批、动作账本等共用能力。
- 移除欢迎动画的“关闭动画”“减少动态效果”按钮及其独立控制状态，恢复正方形画布对应的正圆展示比例；保留系统减少动态效果偏好、资源加载失败提示和重试。

## 6. 终端启动修复

- 修复 `RunController` 构造函数参数属性导致的 `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX`：当前 Node 直接运行 TypeScript 的模式不支持该写法，现改为显式成员声明与赋值。
- 新增普通 Node 子进程导入回归及服务端 TypeScript strip 语法检查，覆盖此前编译构建无法发现的源码启动问题。
