# 自定义模型价格与本地预算验证

## 使用方式

在“设置 → 模型供应商 → 模型编辑”中启用“配置当前模型价格”。分别填写输入、输出、缓存读取、缓存写入价格，单位为 USD / 百万 token。缓存价格可留空，表示未知，不能视为免费。

填写价格来源说明，并核对面板显示的模型、协议和端点后勾选确认。价格不会从外部服务自动查询，也不会触发模型调用。确认时间由服务端记录。USD 是本次唯一支持的预算币种，不进行隐式汇率换算。

全部免费时，四项价格必须明确填 0，并另外勾选“明确确认全部 token 与缓存免费”。未确认的全零占位价格不支持费用预算执行。

关闭价格配置并保存，会将这个模型的本地价格明确标为未知，不继承旧费率。未知状态下普通非费用预算操作仍遵守原授权；启用费用上限时采用保守准入。

## 变更和并发保护

- 保存前，服务端检查面板打开时的模型/协议/端点绑定。另一窗口已改变端点时，返回冲突，保留当前输入；刷新模型设置后重新核对。
- 供应商端点或协议改变后，旧价格确认失效。复制到另一个模型或不同端点的确认不会生效。
- 已开始的预算运行保留原费率快照。下一次派发前和请求组装前核验当前配置，费率/确认变化会阻止继续使用旧预算配置。已发出的请求不能撤回，也不能保证供应商不再计费。
- 模型资格验证的配置指纹包含价格确认信息。价格更新后，原资格报告不自动继承。
- 重复点击保存只发送一次请求；保存失败不清空输入。

## 推荐本地检查（合成数据）

1. 使用独立测试数据目录，先配置一个本地测试模型，不填凭据、不发模型请求。
2. 输入负数、缺少输入/输出价格、未确认的全零，确认保存被拒绝。
3. 设置输入 2、输出 4、缓存留空，填来源并确认。刷新页面确认数据持久存在。
4. 保持编辑器打开，在另一窗口改变端点，回到旧窗口保存价格，应提示配置已变更。
5. 在新端点重新核对价格并保存。关闭配置后保存，再次打开应显示未知。
6. 如已有明确允许消费的模型配置，再另行按本地预算指南验证调用。当前交付的自动化测试使用模拟响应，不代表真实模型质量或真实账单验收。

## 费用边界

这是按用户配置费率计算的本地估算及预留，不是供应商账单硬上限。平台附加费、服务端工具、价格临时变更、缓存规则、供应商忽略参数等都可能导致实际账单不同。请以供应商账单为准。
