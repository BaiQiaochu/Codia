# Codia 模型、资源与 PI SDK 改造验收记录（2026-10-09）

## 已完成范围

- PI SDK 三个包固定为 1.1.0；会话显式接入 Codemode 与 Tool Search，并统一取消、耗时和工具调用 ID。
- 模型能力、思考档位、请求适配和设置保存共用同一份能力来源；补齐 GPT Image 后续型号的添加、默认选择和持久化路径。
- 供应商页将扫描与手动添加移到模型列表上方，加入搜索、类型筛选、请求隔离和键盘交互。
- 图片资源支持登记地址、本机地址和内联内容回退；版本变化后可从失败状态恢复并重试。
- Electron 文件操作先解析真实本机路径，返回结构化错误，并覆盖聊天卡、媒体查看器与右侧文件列表。
- 每次请求从首个工具调用开始聚合为一张执行过程卡；并行调用按调用 ID 配对。
- 2026-10-10 后续修复已删除图片阅读器中的 OCR 面板、离线识别器、运行时路由和打包依赖；生产 HTML 不再包含 OCR/OpenCV 与 ORT 链路。
- Live2D 构建前检查确认 22 项本地资源进入渲染器产物。
